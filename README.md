LibraSys

Description:
LibraSys is a comprehensive library management system that streamlines book reservations and borrowing using advanced software design principles and frameworks. Key features include:

1. Book Reservation: Allows users to browse, reserve, and borrow books efficiently with a user-friendly interface.<br>
2. Factory Design Pattern: Simplifies the creation of different library objects (e.g., books, members, reservations) while promoting scalability.<br>
3. Builder Design Pattern: Facilitates the construction of complex objects like detailed book records and user profiles in a step-by-step manner.<br>
4. Dependency Injection with Guice: Ensures modular and maintainable code by decoupling dependencies, enhancing flexibility and testability.

LibraSys provides a robust, scalable, and maintainable solution for managing library operations with modern design and programming practices.
